# Job Scout v0.6.1

First packaged public release of Job Scout for Chrome and Edge.

## Included

- English interface, notifications, exports, backend errors, and model-analysis instructions.
- English and Chinese README documentation.
- LinkedIn job capture and paste fallback, local application tracking, JSON/CSV export.
- Generic rule-based role classification and DS / DA / Research routing.
- Optional OpenAI analysis with user-supplied resumes and a local backend; API keys stay on the backend.
- Compatibility mapping for application statuses saved by the earlier Chinese UI.

## Install

1. Download `job-scout-v0.6.1.zip` from the release assets and extract it.
2. Open `chrome://extensions` or `edge://extensions` and enable Developer mode.
3. Choose **Load unpacked** and select the extracted `job-scout` folder containing `manifest.json`.
4. Rule mode works without a backend. For API mode, follow `docs/setup.md`; Node.js 22+ and your own OpenAI API account are required.

For an existing installation, back up records using Export JSON. Replace files in the existing extension folder and click Reload; avoid uninstalling if you want to retain browser-local records. Restart the backend after replacing its files.

## Verification and limits

Release publishing is gated on Windows and Linux automated tests. Local browser smoke checks cover the English interface, explicit-send gating, record persistence, stale-result detection, and CSV export. Automated API tests use mocked responses.

Live LinkedIn extraction and real paid OpenAI requests have not yet been verified. Keyword coverage is not a calibrated fit score. No automatic job applications or paid batch analysis are included. Historical model results remain in their original language until re-analyzed.

The `.sha256` asset contains the SHA-256 digest of the ZIP. The package contains no API credentials, personal resumes, or saved job records. This is a Developer-mode package, not a signed Chrome Web Store / Edge Add-ons release.
